Family Dashboard: Privacy Policy

Last updated: October 1, 2026

Family Dashboard is a private, self-hosted dashboard used by one household. This policy explains what Google user data it accesses and how that data is handled.

Data accessed

  • Google Calendar (calendar.readonly): event titles, times, and related event details from the calendars the user authorizes.
  • Gmail (gmail.readonly): for inbox messages from the last few days, the sender, the subject line, and Gmail's short message snippet.

Access is read-only. The app never sends email, creates or changes calendar events, or modifies, labels, or deletes anything in a Google account.

How data is used

The data is used only to show household members their upcoming calendar events and family-relevant email on the dashboard. It is not used for advertising, profiling, or any other purpose.

Storage

OAuth credentials and a short-lived cache of the data above are stored only on the household's own computer, in private folders accessible to that computer's user account. Cached email is replaced on each sync and keeps only recent messages. Nothing is uploaded to any third-party server or database.

Sharing

Google user data is not sold, shared with, or transferred to any third party. It is visible only to members of the household on their private network.

Google API Services User Data Policy

Family Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Any user can revoke the app's access at any time from their Google Account at myaccount.google.com/permissions. Revoking access stops all further syncing. The local cache can be deleted on request.

Contact

Questions about this policy can be sent to the support email shown on the app's Google sign-in screen, or through github.com/rewphus.
